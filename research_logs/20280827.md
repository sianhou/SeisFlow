# 研究日志：2028-08-27

## 当日总结

初步分析了当前重建效果最差的 16 炮数据，可能存在以下问题。

### 1. patch 的有效感受野太小

当前的 i64 表示训练 patch 是 64×64。虽然 patch 之间有 32 像素重叠，但模型每次看到的仍然只有局部区域。

低 PSNR 炮的误差主要位于中下部密集波场区域，这些区域存在：

- 多个事件交叉；
- 同相轴密集；
- 长距离连续事件；
- 局部事件之间存在较强的上下文关系。

64×64 patch 很可能无法判断某个局部波形属于哪一条完整事件，导致局部振幅看起来合理，但相位、事件位置或连续性错误。这与当前 diff 图中的红蓝交替条纹现象一致。

### 2. 每个 patch 使用独立随机噪声

推理时，每个 patch 都执行：

```python
noise = torch.randn(...)
```

这意味着相邻 patch 即使输入条件相近，也会从不同噪声出发，得到不同的重建结果。因此，重叠区域中的两个 patch 不一定一致：

```text
patch A 的右半部分 ≠ patch B 的左半部分
```

Gaussian blending 只能缓解这个问题，不能保证事件相位连续。对于复杂波场，这可能是重要误差来源，也是当前最值得优先验证的问题。

### 3. overlap 拼接只能修复边界，不能恢复缺失上下文

当前 `overlap=32`，使用 Gaussian 权重融合：

```text
weight_patch = gaussian(...)
reconstructed / weight_sum
```

这个方法可以减少明显的接缝，但无法解决：

- patch 内部已经发生的相位错误；
- patch 内部缺少远距离上下文；
- 相邻 patch 对同一事件给出不同预测；
- patch 边缘的事件被截断。

因此，拼接策略主要解决“边界平滑”，不能解决“预测本身不一致”。

### 4. patch 边缘的预测质量可能较差

训练时，模型会看到大量被 patch 截断的事件。推理时，这些边缘位置的预测通常比 patch 中心更不可靠。

虽然当前使用 Gaussian 权重，使 patch 中心权重大、边缘权重小，但最外层 patch 的边缘区域没有其他 patch 充分补偿，仍可能产生较大误差。

更稳定的做法是使用带 halo 的较大输入 patch，只保留中心输出。例如：

```text
输入：128×128
输出：只保留中心 64×64
```

这通常比直接预测完整 64×64 再进行拼接更稳定。

### 5. 复杂炮可能具有更强的全局结构

最差炮集中在 `shot_0115`～`shot_0147` 附近，而且主要误差位于中下部复杂波场。这说明这些样本可能不是简单的局部异常，而是具有以下特点：

- 波场事件更密集；
- 信号频率更高；
- 同相轴弯曲更明显；
- 强弱事件叠加更严重；
- 局部 patch 中存在更多不可区分的模式。

只使用局部 patch 时，模型可能无法从有限区域中判断正确的全局结构。

### 全炮共享噪声实验

针对独立 patch 噪声导致重叠区域不一致的问题，首先设计了全炮数据使用相同噪声的实验：根据输入 SEGY 生成噪声 SEGY，再使用相同方式分割 patch，确保每个重叠区域的初始噪声相同。

实验脚本为：

```text
recon_DiTSeisDimReconNeRF_t_p4_i64_NeRFBands0_ExternalNoise.sh
```

实验结果证明，该方法可以显著降低重叠区域的不一致性，但整体重建效果反而更差。主要原因可能是：全局噪声确实让重叠 patch 更一致，但同时失去了独立噪声带来的多次采样平均收益，因此 PSNR 明显下降。

### 多次独立采样平均实验

进一步对 `shot_0107` 进行了每个 patch 独立采样 1、2、4 次并求平均的实验。4 次平均相对单次采样，EMA 的 PSNR 提高 0.789 dB、MSE 降低 16.6%；无 EMA 的 PSNR 提高 0.447 dB、MSE 降低 9.8%。结果验证了独立噪声的隐式集成作用，也说明增加独立采样次数可以在不重新训练的情况下提高重建精度。

收益存在明显递减，且误差图中的同相轴红蓝条纹仍然存在。因此，多次采样平均主要降低随机误差，不能解决 patch 上下文不足、相位错误等结构性问题。当前结果只来自 bands0、epoch 100 和单炮，下一步需要在 bands3 + EMA、困难炮和完整验证集上确认。

## 2. 最差测试记录、数据特征和可能原因

最差样本分析使用普通 DiT t-p4、epoch 1000 的结果。

- 最差炮是 `shot_0119`：PSNR 16.888 dB，MSE 0.328，MAE 0.287，SSIM 0.531。
- 最差 12 炮主要是：`0115、0118、0119、0127、0128、0132、0134、0137、0141、0144、0147、0174`。
- 大部分最差炮集中在连续的 115～147 区间，说明误差可能与特定炮位置、采集几何或这一段数据分布有关，不像完全随机误差。
- 最差 12 炮的 PSNR 约为 16.89～17.65 dB，SSIM 约为 0.51～0.57。
- 多数最大绝对误差接近 4。数据范围约为 `[-2, 2]`，这通常表示局部出现了正负号相反或相位错位的强振幅。

从差值图看，误差主要沿着地震同相轴和强反射结构分布，不是均匀随机噪声。复杂、弯曲、密集和交叉的反射事件更难重建；深部弱信号区域也有较多残余误差。

可能原因按优先级排列如下：

1. **patch 上下文不足。** 64×64 patch 很难完整描述跨越较大范围的倾斜或弯曲同相轴。
2. **重叠 patch 的初始噪声不一致。** 每个 patch 独立生成随机噪声，会让同一重叠位置从不同初始状态开始生成。
3. **patch 边界上下文不同。** 即使共享初始噪声，各 patch 仍独立执行模型和 ODE，边缘位置看到的邻域不同，最终结果仍可能不完全一致。
4. **高频相位和振幅误差。** 对地震数据来说，小的相位偏移也会产生较大的逐像素误差。
5. **困难炮分布不足。** 最差炮集中在连续区间，可能说明训练数据没有充分覆盖该采集几何或该类复杂结构。
6. **后期参数波动。** 无 EMA 的普通 DiT 在 1000 epoch 后波动明显，可能使部分炮变好、部分炮变差。
7. **全局裁剪和归一化影响。** 强振幅被裁剪后，局部符号或相位错误容易达到最大误差 4；全局尺度也可能压缩弱信号差异。

当前差值图中的误差以结构误差为主，没有看到误差完全由规则方格接缝控制。因此，独立 patch 噪声是重要嫌疑，但可能不是唯一原因。

### 5.1 独立噪声原本具有重叠平均作用

重建时，同一像素会由多个重叠 patch 重复预测，再通过高斯权重融合。使用独立噪声时，各 patch
的生成误差相关性较弱，融合过程能够抵消一部分误差，效果类似多次预测的集成平均。

改成全局统一噪声后，重叠 patch
的初始误差更相关。融合仍然存在，但相关误差不容易互相抵消。因此，统一噪声虽然让重叠区域拥有相同初值，却同时失去了独立预测带来的平均收益。当前结果说明，损失的平均收益大于共享初值可能带来的接缝改善。

#### shot_0107 的隐式集成验证

为了直接验证这个结论，使用 NeRF bands0、epoch 100 的 `shot_0107`，选择被 4 个 patch 同时覆盖的 368,640 个像素。对每个像素分别取
1、2、3、4 个 patch 预测求平均，并枚举对应数量下的所有组合，计算期望 MSE。

| 权重   | 噪声方式       | 单个预测 MSE | 4 个预测平均 MSE |  MSE 降幅 |
|--------|----------------|-------------:|-----------------:|----------:|
| EMA    | patch 独立噪声 |        0.661 |            0.482 | **27.1%** |
| EMA    | 全局统一噪声   |        0.647 |            0.622 |      3.9% |
| 无 EMA | patch 独立噪声 |        0.585 |            0.444 | **24.2%** |
| 无 EMA | 全局统一噪声   |        0.606 |            0.582 |      3.9% |

独立噪声下，参与平均的 patch 从 1 个增加到 4 个时，MSE 持续快速下降；全局噪声下的 MSE
曲线几乎不变。这说明独立噪声产生了误差相关性较低的多个预测，重叠融合相当于一次隐式集成。全局噪声使预测误差高度相关，因此增加参与融合的
patch 数量也难以消除误差。

![shot_0107 独立噪声隐式集成验证](images/20280827/shot0107_implicit_ensemble_evidence.png)

进一步统计融合前的重叠输出标准差：EMA 从独立噪声的 0.1267 降到全局噪声的 0.0417，无 EMA 从 0.1118 降到 0.0405。全局噪声确实提高了
patch 一致性，但这种一致性也意味着误差更相关。当前结果应解释为“共享成功，但失去了集成平均收益”，而不是“共享噪声没有生效”。

### 5.4 只使用了一个固定全局随机种子

当前全局噪声是固定 seed 的一次随机实现，它可能恰好对应一个较差样本。

独立噪声相当于在一幅炮内使用大量不同的随机实现，再通过重叠融合进行平均。全局噪声则让多个重叠 patch 共享同一份随机实现，因此两者并不是完全等价的单次随机种子对比。

不过，之前 75 炮的统一噪声结果全部变差，说明当前退化不只是 `shot_0107` 或某一个随机种子的偶然问题。后续仍应生成多个不同 seed 的全局噪声，分别完成整炮重建后统计均值和方差；也可以对多个完整的全局噪声重建结果求平均，判断能否同时获得空间一致性和集成收益。

### 5.5 全局噪声结果更容易出现大振幅和裁剪

`shot_0107` 融合前的 patch 输出中，接近 `±1` 的数值比例为：

| 权重 | patch 独立噪声 | 全局统一噪声 |
| --- | ---: | ---: |
| EMA | 0.77% | 1.28% |
| 无 EMA | 0.30% | 0.81% |

独立预测融合后，极端值容易被多个重叠预测平均掉。全局噪声的输出误差相关性更强，极端值无法在融合中充分抵消，因此保留了更多强振幅随机误差。

重建图中也能看到，全局噪声结果的振幅更强，但这些强振幅与真实数据的相位和振幅并不完全对应。由于推理使用 `--clip_recon -1 1`，更高的饱和比例也会增加局部符号、相位和振幅错误对 MSE、PSNR 的影响。

## 6. 多次独立采样平均实验

### 6.1 实验目的

全局噪声实验表明，共享噪声会使重叠 patch 的误差高度相关，从而失去融合阶段的隐式集成收益。为了直接利用这一现象，在不重新训练模型的条件下，对同一个 patch 使用多个独立噪声进行采样，再对 patch 输出求平均。

本实验回答两个问题：

1. 增加独立采样次数能否稳定提高最终重建指标；
2. 多次采样平均主要改善随机误差，还是能够修复结构性误差。

### 6.2 实验设置

- 模型：DiT-NeRF t-p4 i64，NeRF bands0；
- checkpoint：epoch 100；
- 测试数据：`shot_0107`；
- 权重：EMA 和无 EMA；
- 独立采样 seed：0、1、2、3；
- 对比采样次数：1、2、4；
- 每次采样先得到完整 patch 输出，再对前 1、2、4 份输出逐像素求平均；
- 平均后的 patch 使用相同的 Gaussian blending 重建整炮；
- 推理仍使用 `--clip_recon -1 1`。

该实现只运行 4 次独立采样，并复用结果构造 1、2、4 次平均，因此没有重复执行 1+2+4 共 7 次采样。

### 6.3 实验结果

| 权重 | 采样次数 | PSNR | MSE | MAE | SSIM | 最大绝对误差 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| EMA | 1 | 15.004 | 0.505 | 0.405 | 0.3570 | 4.000 |
| EMA | 2 | 15.612 | 0.439 | 0.377 | 0.3612 | 3.825 |
| EMA | 4 | **15.793** | **0.421** | **0.368** | **0.3645** | **3.464** |
| 无 EMA | 1 | 15.522 | 0.449 | 0.383 | 0.3542 | 4.000 |
| 无 EMA | 2 | 15.779 | 0.423 | 0.372 | 0.3538 | 3.860 |
| 无 EMA | 4 | **15.969** | **0.405** | **0.363** | **0.3578** | **3.559** |

4 次平均相对单次采样的变化为：

| 权重 | PSNR 变化 | MSE 变化 | MAE 变化 | SSIM 变化 |
| --- | ---: | ---: | ---: | ---: |
| EMA | +0.789 dB | -16.6% | -9.2% | +0.0075 |
| 无 EMA | +0.447 dB | -9.8% | -5.3% | +0.0036 |

指标曲线显示，随着独立采样次数从 1 增加到 2、4，PSNR 总体提高，MSE 和 MAE 持续下降。EMA 的 SSIM 单调提高；无 EMA 的 SSIM 在 2 次时轻微下降，但 4 次时超过单次结果。

![shot_0107 多次独立采样指标变化](images/20280827/shot0107_multisample_metric_curves.png)

误差图显示，多次平均后误差振幅有所减弱，最大绝对误差也从 4 降到约 3.46～3.56；但是主要红蓝条纹仍沿相同的同相轴分布，说明事件位置、相位和连续性方面的系统误差没有被消除。

![shot_0107 多次独立采样误差图](images/20280827/shot0107_multisample_error_maps.png)

### 6.4 研究结论

1. **多次独立采样平均有效。** EMA 和无 EMA 的 PSNR、MSE、MAE 在 4 次平均时都明显优于单次采样，进一步验证了独立噪声的隐式集成作用。
2. **EMA 从多次采样中获益更大。** EMA 的 PSNR 提升 0.789 dB，高于无 EMA 的 0.447 dB。不过在 epoch 100 的这个单炮结果中，无 EMA 的绝对 PSNR 仍然更高，不能据此否定后期 checkpoint 中 EMA 的整体优势。
3. **收益存在递减。** EMA 从 1 次增加到 2 次提高 0.607 dB，从 2 次增加到 4 次只再提高 0.182 dB；无 EMA 对应提高 0.257 dB 和 0.190 dB。计算成本则随采样次数近似线性增加。
4. **多次平均主要降低随机方差。** 极端误差、MSE 和 MAE 明显下降，但误差结构的位置基本不变。它无法解决感受野不足、事件相位错误和长距离上下文缺失。
5. **当前只能作为初步证据。** 实验仅使用 bands0、epoch 100 和 `shot_0107`，不能直接推断完整验证集和当前最佳 bands3 + EMA 模型的收益。

### 6.5 下一步计划

1. 优先在当前最佳的 bands3 + EMA checkpoint 上比较 1、2、4 次独立采样。
2. 先选择最差 16 炮和若干简单炮，确认困难炮与简单炮的收益是否一致。
3. 如果大部分炮都稳定提高，再运行完整 75 炮测试。
4. 同时记录重建精度和推理时间，评估 2 次采样与 4 次采样的性价比。
5. 将多次采样平均作为推理端优化；训练端仍回到扩大有效上下文、halo 输入和困难炮重采样等主线。
