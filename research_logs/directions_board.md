# 研究方向看板

## 下一步重点

### [Patch Size 与有效上下文](directions_patch_size.md)

- 当前判断：困难炮的长距离、弯曲和交叉同相轴结构误差与有限上下文假设一致，但当前没有 NeRF-DiT bands3 + EMA 的 i64/i128 严格对照，增大 patch size 仍是证据不足的假设。下一步只做有停止条件的 i64/i128 直接筛选。
- 下一步计划：
  1. 明确 i64/i128 的共同64×64目标区域、训练预算、随机采样控制和停止条件。
  2. 使用 i128/overlap101 重建并核对每炮416块，完成单 batch、checkpoint 恢复和单炮标准拼接 smoke test。
  3. 短程对比 i64/overlap32 与 i128/overlap101，重点评价固定最差16炮、高能量 patch、结构误差和高重叠成本。
  4. 仅在 i128 对共同目标区域产生稳定收益后继续完整训练和整炮比较；否则暂停扩大 patch，不进入 i256。
- 最后更新：2026-08-28

### [AugmentedDiT 架构对照](directions_augmented_dit.md)

- 当前判断：AugmentedDiT 的模型、wrapper、独立训练/采样入口、hwgpu 训练/重建脚本和定向测试已经完成，可以启动 T/P4、i64、NeRF bands0 的端到端对照；尚无训练结果，不能判断其效果优于或劣于传统 DiT。
- 下一步计划：启动 AugmentedDiT-T/P4 i64 bands0 训练，按每100 epoch与 DiT-T/P4 比较同一验证集的 PSNR、MSE、收敛、显存和计算成本；若存在稳定差异，再统一时间编码或参数预算做归因消融。
- 最后更新：2026-08-31

## 保留

### [多次独立采样平均](directions_multisampling.md)

- 当前判断：多次独立采样平均已经显示出降低随机误差和提高 PSNR 的效果，但它不能解决 patch 上下文不足等结构性误差，不是当前关键问题。
- 下一步计划：暂不优先扩展；后续需要推理端优化时，再在 bands3 + EMA、困难炮和完整验证集上评估精度与推理成本。
- 最后更新：2028-08-27

## 暂停

### [Halo 中心裁剪](directions_halo.md)

- 暂停原因：i64 halo 对总体 pooled PSNR 没有稳定收益，在高能量困难 patch 上反而一致退化；逐 patch 平均增益主要由中心为空或很安静的离群 patch 拉高，继续实现完整 i64 halo 铺炮的预期收益不足。
- 重新考虑条件：最佳 bands3 + EMA 的完整验证集显示困难 patch 中心区域稳定优于边缘，或者 i128 输入预测中心64在固定困难炮上稳定改善，并出现明确的边缘质量差异。
- 下一步计划：暂不继续实现或扩展 i64 halo；先完成 Patch Size 主线的 i64/i128 中心64直接对照，仅在满足重新考虑条件时使用同一 i128 checkpoint 比较完整输出与中心裁剪输出。
- 最后更新：2026-08-28

### [全局共享噪声](directions_shared_noise.md)

- 暂停原因：单个全局共享噪声 seed 虽提高了 patch 一致性，但使误差高度相关；EMA 和无 EMA 的 75 炮结果全部退化，平均 PSNR 分别下降 0.937 dB 和 0.789 dB。
- 重新考虑条件：多次独立采样验证完成后，若仍需兼顾空间一致性与集成收益，再测试多个完整全局噪声 seed 的整炮重建集成。
- 下一步计划：暂不继续扩展单 seed 共享噪声实验，保留现有实现和证据，等待多采样主线结果后再评估。
- 最后更新：2028-08-27
