### 模型约束初至波反演方法

初至波走时反演的目标是利用观测初至时间建立近地表速度模型。由于走时与慢度之间具有近似线性关系，本文在反演过程中采用慢度作为更新变量。速度 (
v_i) 与慢度 (s_i) 的关系为

[
s_i=\frac{1}{v_i},
]

其中，(i) 为模型网格单元编号。

对于第 (r) 条射线，其理论初至走时可表示为

[
t_r^{\mathrm{cal}}=\sum_i L_{ri}s_i,
]

其中，(L_{ri}) 表示第 (r) 条射线在第 (i) 个网格单元中的等效路径长度。观测走时与计算走时之间的残差为

[
e_r=t_r^{\mathrm{obs}}-t_r^{\mathrm{cal}}.
]

当 (e_r>0) 时，说明当前模型计算走时偏小，射线路径上的速度偏高，需要增加慢度；当 (e_r<0) 时，说明当前模型计算走时偏大，射线路径上的速度偏低，需要降低慢度。

在固定射线路径条件下，初至波反演可写为线性化形式：

[
\mathbf{G}\Delta \mathbf{s}=\Delta \mathbf{t},
]

其中，(\mathbf{G}) 为路径长度灵敏度矩阵，(\Delta \mathbf{s}) 为慢度更新量，(\Delta \mathbf{t})
为走时残差向量。本文采用归一化反投影方式计算慢度更新，而不显式求解大型稀疏矩阵。对于第 (r) 条射线，定义归一化因子

[
D_r=\sum_i L_{ri}^2+\varepsilon,
]

则该射线对第 (i) 个网格单元的慢度更新贡献为

[
\delta s_{ri}=\frac{e_r L_{ri}}{D_r}.
]

对所有穿过网格单元 (i) 的射线贡献进行平均，得到该单元的慢度更新量：

[
\Delta s_i=\frac{1}{H_i}\sum_r \delta s_{ri},
]

其中，(H_i) 为穿过第 (i) 个网格单元的射线数。随后按松弛因子 (\alpha) 更新慢度：

[
s_i^{k+1}=s_i^k+\alpha \Delta s_i,
]

并由慢度反算速度：

[
v_i^{k+1}=\frac{1}{s_i^{k+1}}.
]

由于初至波传播路径依赖于速度模型，因此本文采用非线性迭代反演策略，即每次迭代均根据当前速度模型重新计算初至走时和射线路径。

为提高反演结果的稳定性和地质合理性，本文引入结构约束模型。结构约束模型用标签网格表示：

[
C_i=0,1,2,\cdots,
]

其中，不同标签代表不同的浅表地质单元或约束区域。在反演更新后，对速度模型施加结构保持平滑，即仅在相同结构标签内部进行平滑：

[
v_i^{\mathrm{smooth}}=
\frac{4v_i+\sum_{j\in N_i, C_j=C_i}v_j}
{4+N_i^{\mathrm{same}}},
]

其中，(N_i) 为第 (i) 个网格单元的邻域，(N_i^{\mathrm{same}})
为与当前网格具有相同结构标签的邻近单元数量。该约束能够增强同一地质单元内部速度的连续性，同时避免不同结构单元之间的过度平滑。

对于具有明确地质意义的非零结构区域，还可进一步施加区域投影约束。设第 (k) 个结构区域为

[
\Omega_k={i\mid C_i=k}, \quad k>0,
]

其平均速度为

[
\bar{v}*k=\frac{1}{|\Omega_k|}\sum*{i\in \Omega_k}v_i.
]

则区域内速度按下式向平均速度靠近：

[
v_i \leftarrow (1-\beta)v_i+\beta \bar{v}_k,\qquad i\in \Omega_k,
]

其中，(\beta) 为结构投影强度系数。当 (\beta=0) 时不施加投影；当 (0<\beta<1) 时为弱约束；当 (\beta=1) 时，同一结构区域内速度被约束为常数。

综上，本文模型约束初至波反演流程如下：

[
\begin{aligned}
&\text{输入初始速度模型 } v^0,\ \text{观测初至走时 } t^{\mathrm{obs}},\ \text{结构约束模型 } C;\
&\text{对于 } k=1,2,\cdots,n_{\mathrm{iter}}:\
&\quad \text{1. 根据当前速度模型计算初至走时 } t^{\mathrm{cal}};\
&\quad \text{2. 计算走时残差 } e=t^{\mathrm{obs}}-t^{\mathrm{cal}};\
&\quad \text{3. 回溯射线路径，计算路径长度灵敏度 } L_{ri};\
&\quad \text{4. 采用归一化反投影计算慢度更新量 } \Delta s_i;\
&\quad \text{5. 更新慢度和速度模型;}\
&\quad \text{6. 施加速度上下限约束;}\
&\quad \text{7. 根据结构标签进行结构保持平滑;}\
&\quad \text{8. 对非零结构区域施加区域投影约束;}\
&\quad \text{9. 计算并输出走时拟合误差。}\
&\text{输出最终近地表速度模型。}
\end{aligned}
]

该方法通过初至走时残差驱动速度模型更新，同时利用结构约束模型限制速度变化的空间形态。与常规无约束初至波反演相比，模型约束反演能够在保持数据拟合能力的基础上增强速度模型的地质合理性，减少不稳定异常，提高复杂近地表条件下的反演精度。
